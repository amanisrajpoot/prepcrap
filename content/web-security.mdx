## Visual Concept: JWT vs Session Auth

```text
 ┌───────────────────────┐         ┌───────────────────────┐
 │   SESSION COOKIES     │         │ JSON WEB TOKENS (JWT) │
 └───────────┬───────────┘         └───────────┬───────────┘
             │                                 │
 [Server generates Session ID]     [Server signs Payload]
 [Stores ID in Server Memory]      [No Server Memory used]
             │                                 │
 [Sends ID in HTTPOnly Cookie]     [Sends JWT to Client]
             │                                 │
 [Client sends Cookie on req]      [Client sends JWT in Header]
             │                                 │
 [Server looks up Session ID]      [Server verifies Signature]
             │                                 │
 * Stateful (harder to scale)      * Stateless (easy to scale)
 * Easy to invalidate/logout       * Hard to invalidate early
```
