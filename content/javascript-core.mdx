concept: "JavaScript is single-threaded but achieves concurrency through the Event Loop. Understanding how the Call Stack, Web APIs, Microtask Queue (Promises), and Macrotask Queue (setTimeout) interact is crucial. Furthermore, concepts like Closures (functions retaining access to their lexical scope) and Prototypal Inheritance form the bedrock of the language."
interviewScript: "When explaining JavaScript's concurrency model, I emphasize that JS itself is synchronous and single-threaded. Concurrency is handled by the browser or Node.js environment. When an async operation like a fetch request occurs, it's handed off to Web APIs. Once complete, its callback is pushed to a queue. The Event Loop constantly checks if the Call Stack is empty; if it is, it pushes the oldest task from the queue onto the stack. Crucially, Microtasks (like Promise callbacks) have higher priority than Macrotasks (like setTimeout). This means the Microtask queue must be completely emptied before the next Macrotask runs."
