## Deep Dive: State Management Patterns

The state management landscape has evolved dramatically. Understanding the tradeoffs between approaches is a senior-level skill.

### The State Spectrum

```
Local ←————————————————————————————→ Global
useState → useReducer → Context → Zustand/Jotai → Redux
```

### Server State vs Client State

This is the most important distinction modern React developers must make:

| | Server State | Client State |
|---|---|---|
| **Source of truth** | External database/API | In-memory |
| **Caching** | Stale-while-revalidate | Always fresh |
| **Sync** | Async, may fail | Synchronous |
| **Tool** | TanStack Query, SWR | useState, Zustand |
