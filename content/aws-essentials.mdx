## Architecture Quick Reference

| Requirement | Preferred AWS Service |
|---|---|
| Hosting a React SPA | S3 + CloudFront |
| Running a Docker container | ECS (Fargate) |
| Event-driven, short scripts | AWS Lambda |
| Relational data with complex JOINs | Amazon RDS (PostgreSQL/MySQL) |
| Massive scale Key-Value store | Amazon DynamoDB |
| Decoupling microservices | Amazon SQS & SNS |
| User Authentication | Amazon Cognito |
