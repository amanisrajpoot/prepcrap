## Code Review Scenario: Mutable Defaults

Look at this common Python mistake:

\`\`\`python
def add_employee(emp_name, emp_list=[]):
    emp_list.append(emp_name)
    return emp_list

print(add_employee("John")) # ['John']
print(add_employee("Jane")) # ['John', 'Jane'] - Wait, what?
\`\`\`

**The Fix:** Default arguments are evaluated *once* when the function is defined, not every time it's called. Always use `None` for mutable defaults:

\`\`\`python
def add_employee(emp_name, emp_list=None):
    if emp_list is None:
        emp_list = []
    emp_list.append(emp_name)
    return emp_list
\`\`\`
