## Visual Concept: REST vs GraphQL

```text
 ┌──────────────────────────┐    ┌──────────────────────────┐
 │ REST API (Multiple Trips)│    │ GRAPHQL API (One Trip)   │
 │                          │    │                          │
 │ Client                   │    │ Client                   │
 │   │ GET /users/1         │    │   │ POST /graphql        │
 │   ├───────────────────>  │    │   │ query {              │
 │   │      {user data}     │    │   │   user(id:1) {       │
 │   <───────────────────┤  │    │   │     name             │
 │   │ GET /users/1/posts   │    │   │     posts { title }  │
 │   ├───────────────────>  │    │   │   }                  │
 │   │      [post data]     │    │   │ }                    │
 │   <───────────────────┤  │    │   ├───────────────────>  │
 │                          │    │   │                      │
 │ * Prone to over-fetching │    │   │ { user, posts }      │
 │ * Prone to under-fetching│    │   <───────────────────┤  │
 └──────────────────────────┘    └──────────────────────────┘
```
