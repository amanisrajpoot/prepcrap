## Deep Dive: Performance Optimization

Performance is not an afterthought — it's a feature. Senior engineers build performance-aware applications from day one.

### The Critical Rendering Path

Understanding how the browser renders content is fundamental:

1. **Parse HTML** → Build the DOM tree
2. **Parse CSS** → Build the CSSOM tree  
3. **Combine** → Create the Render tree
4. **Layout** → Calculate geometry
5. **Paint** → Fill in pixels
6. **Composite** → Layer composition
